SmartMeal

A meal planning web app that helps people eat well on a budget, with prices shown in Kenyan shillings.

  • Browse recipes with price, difficulty, prep time and cook time.
  • Build meal plans and see the total cost.
  • Create shopping lists and save favorite recipes.
  • Track a weekly budget and set dietary preferences.
  • React
  • TypeScript
  • Node.js
  • Express
  • Tailwind CSS
  • PostgreSQL

AI Inventory System

A stock management app for small businesses, with insights that help spot trends and unusual stock levels.

  • User login, with each person managing their own stock.
  • Add, edit and delete items, suppliers and locations.
  • Export inventory to a file.
  • Insights charts, plus machine learning code for demand forecasting and unusual stock detection.
  • Python
  • Django
  • scikit-learn
  • pandas
  • Plotly
  • Bootstrap
